# IndoGulf 🌍🇮🇳

## India → Gulf B2B Export Marketplace

A production-ready marketplace connecting Indian exporters with Gulf country importers (UAE, Saudi Arabia, Qatar, Oman, Kuwait, Bahrain).

## ✨ Features

* **3 User Roles:** Admin · Seller/Exporter · Buyer/Importer
* **Full Auth System:** Register, Login, Logout, Remember Me, CSRF
* **Product Management:** Add, Edit, Delete, Image Upload
* **RFQ System:** Buyers send quotes, Sellers manage & reply
* **WhatsApp Integration:** One-click contact on every product
* **Admin Panel:** Approve sellers, manage products, monitor RFQs
* **Search & Filter:** By category, country, price, MOQ
* **SEO Ready:** Meta tags, Open Graph, slug URLs
* **Mobile Responsive:** Tailwind CSS
